# Project Brief: Welly Clone (getwelly.com)

## 1. Project Overview
This project is an academic web development clone of [Welly](https://www.getwelly.com), a modern first aid and wellness brand known for its playful, clean, and vibrant visual design. The objective is to reproduce the brand's aesthetic, layout responsiveness, and key interactive frontend features.

## 2. Goals & Objectives
- Develop a clean, accessible, and responsive website adhering to semantic HTML5 standards.
- Recreate Welly's design language: vibrant color palette, modern typography, card-based product layouts, and playful micro-interactions.
- Implement responsive grid systems and utility classes using **Bootstrap 5**.
- Provide custom styling and animations using modern CSS3.
- Handle frontend interactivity (modals, mobile navigation, cart preview, filtering/toggles) using vanilla JavaScript.

## 3. Tech Stack
- **HTML5**: Semantic document structuring
- **CSS3 / Bootstrap 5 (CDN)**: Layout grid, responsive utilities, custom theming
- **JavaScript (ES6+)**: DOM manipulation, interactive components
- **Assets**: Optimized web images, SVG icons

## 4. Key Sections & Components
- **Announcement Bar & Navigation**: Global banner for offers, branding logo, navigation links, search, account, and cart drawer trigger.
- **Hero Banner**: Engaging headline, call-to-actions (CTAs), and brand imagery.
- **Featured Categories / Best Sellers**: Grid of popular tins and first aid packs with pricing, badges, and quick-add actions.
- **Value Proposition / Brand Story**: Icon blocks highlighting waterproof features, fun patterns, and eco-friendly packaging.
- **Customer Reviews & Social Proof**: Testimonials slider or cards highlighting user satisfaction.
- **Footer**: Newsletter signup, navigation links, copyright, and social media links.
